📖 Usage

To use this repository in Alpine Linux:

  1. Add the public key: 
    wget -O /etc/apk/keys/melange.rsa.pub https://lucianolacurcia.github.io/apk_repo_page/keys/melange.rsa.pub
  2. Add repository to /etc/apk/repositories: 
    echo "https://lucianolacurcia.github.io/apk_repo_page/x86_64" >> /etc/apk/repositories
  3. Update and install: 
    apk update
apk add supply-chain-challenge-app
