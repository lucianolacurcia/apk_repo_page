📖 About SBOMs

SBOMs (Software Bill of Materials) provide a complete inventory of all software components in the container, including:

  • Base image packages
  • Installed APK packages
  • All transitive dependencies
  • Version information and metadata

Formats:

  • .spdx.json - SPDX format (JSON)
  • .cyclonedx.json - CycloneDX format (JSON)
